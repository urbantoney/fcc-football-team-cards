# Football Team Cards

A football team cards application built as part of the freeCodeCamp JavaScript Algorithms and Data Structures curriculum.

## Features

- Display football team information
- Display player cards dynamically using JavaScript
- Identify the team captain
- Filter players by position
- Show all players or specific positions using a dropdown menu

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

- Working with objects and arrays
- Accessing and displaying data from objects
- DOM manipulation
- Using the `map()` method
- Using the `filter()` method
- Event listeners
- Dynamic rendering of content

## Project Preview

The application displays team information, player cards, and allows users to filter players by position using a dropdown menu.
